# 参考图视觉分析

## 1. 任务与输出

根据提供的完整参考图，以及可选的明确编辑要求，输出一份用于可编辑复刻的视觉草案。自主识别需要替换的图片、设计文字、装饰、背景及叠放关系。用户要求优先；未指定时，独立照片按可替换内容处理，设计文字保留为文字层。

只返回一个 JSON 对象，顶层恰为 `background`、`slots`、`texts`、`overlays`、`layer_order`、`questions`。不附解释、Markdown 或第二份清单。草案表达看到了什么和如何拆分，不选择客户文件，不执行制作，不声明素材或工程已经完成。

## 2. 对象如何划分

- **slots：图片内容。** 一张独立显示、需要替换的照片为一个槽。相框、衬纸、贴纸和独立文案另列；照片中自然拍到的人、物品、招牌或衣服文字通常留在照片里。相册、手机或纸板本身作为排版载体时，检查其中独立显示的小照片，不因为它们嵌在大组合内就漏掉；若只是照片中偶然拍到的物体，不递归拆解。
- **background：最底层。** 摄影底图默认由一个满画布图片槽表示。前景遮住后露出的多个局部仍属于同一底图，不新增槽。纸张、纯色、纹理底板是固定背景；前景的纸板和卡片是装饰，不因面积大而成为背景。多张照片拼满画面不等于一张摄影底图。
- **texts：独立设计文字。** 能用文字排版表达的标题、标签、数字和文案都放在这里，包括暂时不允许改字的文字。准确抄录可辨内容，不把照片内部的文字抽出。只有特定标志、特殊字形或与插画不可分的文字，才随装饰保留。
- **overlays：装饰制作单元。** 同处一层、需要一起编辑的局部图案可以合并，内部点缀用描述表达。需分别跟随不同照片、单独编辑或穿插到不同层的部分才拆开；不逐笔拆对象，也不把跨越多个层级的内容合为一层。写实的猫贴纸、月亮、食物或色卡不自动成为客户照片，按设计用途判断。
- **不规则与跨格内容。** 独立人像剪影仍是图片槽。若同一张照片的人物越过分隔线，只有需要单独遮挡的一部分才另列 `cutout` 槽，并引用原照片；不能把客户人脸变成固定生成装饰。仅仅是同一个人，不足以证明使用同一张源照片。

对于界面、水印或标识，先判断是否属于需要复刻的设计。明确的截图外围界面可不列制作项；会影响复刻范围的取舍写入 `questions`，不凭猜测删改难辨内容。

## 3. 范围、归属与叠放

所有元素统一用 `source_bbox_1000=[x_min,y_min,x_max,y_max]`：相对完整参考图的 0–999 整数坐标，横纵轴分别归一化；左上角 `[0,0]`，右下边界编码 `[999,999]`。必须满足 `0≤x_min<x_max≤999`、`0≤y_min<y_max≤999`。直接判断四边占整图的比例；右下角不是宽高，不输出像素坐标或局部裁图坐标。

| 类型 | 框的含义 |
|---|---|
| 普通照片槽 | 照片显示窗口的范围。有框照片取内口，排除外框和相纸文字；前景贴纸遮住照片时，不把窗口缩成剩余的几个露出块。 |
| 不规则图片槽 | 非矩形照片区域或剪影的轴对齐包围框。说明实际轮廓和遮挡，不能用包围框代替遮罩。 |
| 文字 | 该项文字完整排版区域，包含属于这一项的多行文字；不吞入底板。 |
| 装饰 | 该制作单元所有成员的完整外包围框，包括线段末端、附属图案和阴影等实际属于它的内容；排除已另列的文字。 |
| 摄影背景槽 | `[0,0,999,999]`，表示铺满画布，不按露出部分缩框。固定背景无需 bbox。 |

旋转对象使用轴对齐包围框，倾斜、圆角、心形开口、柔边等写入外观说明。被遮住的规则窗口可依据可见边缘合理补全；超出画布部分截至画布边界，无法确定的隐藏范围不要编造。明显影响布局的估计写入 `questions`。

相框与照片分别记录外轮廓和内口。装饰若是相框，说明照片开口透明，不把参考照片或已列文字烘焙进框。`attachment` 表达对照片的归属和上下关系，不改变任一对象的框，也不意味着两者已经合成素材。

`layer_order` 是唯一的前后顺序，从底到顶。每个对象必须且只能出现一次，包括有 `attachment` 的装饰；附件的 above/below 必须与该顺序一致。看不出且互不重叠的对象可采用任一稳定顺序；有实际遮挡而无法判断时记录问题。一个对象无法用单一前后顺序表达时，按可观察的层拆分；无法可靠拆分则说明缺口。

## 4. JSON 字段约定

只使用本节字段。表中标为可选的字段可以省略，其他字段必填。省略表示未提供该信息，不表示空内容；只有明确允许的位置使用 `null`。数组无项目用 `[]`；非空字符串不能用空串占位。无备注就省略 `review_notes`。

### 共同字段

`slots`、`texts`、`overlays` 中每项均有：

| 字段 | 类型与含义 |
|---|---|
| `id` | 唯一字符串，跨三类不重复；小写字母开头，后接小写字母、数字、下划线或短横线，最多 64 字符。 |
| `label` | 非空简短名称，指明对象，而非重复整段外观。 |
| `source_bbox_1000` | 上节定义的四个整数，取值 0–999；字段名中的 1000 表示归一化刻度，不是允许的最大值。 |
| `review_notes` | 可选非空字符串，记录估计依据、归属或制作限制；需要解决的问题同时写入 `questions`。 |

### background

两种形式择一：

- 固定底层：`{"mode":"fixed","kind":"solid","background_brief":"暖白色底"}`。`kind` 为 `solid` / `texture` / `photo` / `unknown`；`background_brief` 非空，只描述底层外观，不能把前景照片或文字合进背景。可选 `review_notes`。只有用户明确要求保留摄影底图时使用固定 `photo`，同时必填非空 `preserve_reason`，记录该要求；其他 kind 不写此字段。
- 可替换底层：`{"mode":"slot","kind":"photo","slot_id":"scene"}`。同样四种 `kind` 可用；`slot_id` 引用不带 `source_slot_id` 的满画布槽，可选 `review_notes`，不写 `background_brief` 或 `preserve_reason`。摄影底图对应槽的 `mode` 为 `photo`；其他背景替换需求按实际显示方式记录。

不存在独立可见底层时，可用固定 `unknown` 并说明被覆盖，不能声称还原了未知底图。`unknown` 的不确定内容应进入 `questions`。

### slots

共同字段之外：

- `mode`：`photo`（保留照片内部环境）/ `photo_feather`（照片柔边）/ `cutout`（分离主体剪影）/ `unknown`（显示方式不确定）。心形、星形等窗口中的完整照片仍为 `photo`。
- `display_brief`：可选非空字符串。非矩形窗口、旋转、柔边和剪影必须提供，描述可见轮廓、朝向和必要的遮挡；普通正放矩形可省略。这是外观描述，不是可执行遮罩或变换参数。
- `source_slot_id`：仅在确知剪影来自另一已列照片时使用，且本项必须为 `cutout`。引用一个无 `source_slot_id` 的 `photo` 或 `photo_feather` 槽，不能自指。表示复用同一客户源图，不另要一张上传；两项 bbox 均描述各自在参考中的显示位置，并非源图裁剪坐标。不确定是否同源时省略并提问。

### texts

共同字段之外：

- `default_text`：非空字符串或 `null`。字符串是准确内容，多行用 `\n`。一段文字有关键部分无法辨认时整项为 `null`，已读出的片段可放备注，不用问号或猜词补齐。用户明确提供替换文案时采用该文案，并在备注说明来源。
- `style_brief`：可选非空字符串，描述颜色、字形特征、对齐和行列关系；不要求字体文件、像素字号。明显影响复刻的排版特征应提供。

### overlays

共同字段之外：

| 字段 | 规则 |
|---|---|
| `action` | `basic_shape` 或 `reference_generate`，只表示制作建议。 |
| `shape` | 仅 `basic_shape` 必填，格式 `{"kind":"rectangle","appearance_brief":"浅蓝色半透明矩形，无描边"}`。kind 为 `rectangle` / `rounded_rectangle` / `ellipse` / `dashed_rectangle` / `line` / `polyline`；appearance_brief 非空，说明颜色、填充/描边、线的方向和连接等关键外观。暂不输出像素线宽、局部路径点或圆角数值。 |
| `generation_brief` | 仅 `reference_generate` 必填非空字符串，描述完整对象的形状、方向、颜色、质感、内部排列及透明开口；该 action 不写 `shape`。`basic_shape` 省略此字段，不能填 `null`。 |
| `attachment` | 可选，省略等同无依附。可为 `null` 或 `{"slot_id":"photo_a","position":"above"}`，position 为 `above` / `below`；引用非背景图片槽。跨多张照片的独立装饰不强行归属其中一张。 |
| `requires_exact_content` | 可选布尔值，省略默认 `false`。特定标识、字样等内容必须精确保留时填 `true`，不代表生成可以保证准确。 |
| `text_content` | 仅 `reference_generate` 可用；含必须保留的文字时填准确非空字符串，无法读清填 `null` 并提问；两种情况均令 requires_exact_content 为 true。无文字时省略，不重复已列入 texts 的内容。 |

直线、规则折线、虚线、简单底板和几何描边优先 `basic_shape`；文案走 `texts`。`reference_generate` 用于这些方式不能合理表达的纹理、撕纸、插画、特殊字形或复杂装饰组合。不要仅因为内容固定、有文字或需要一起移动就选择生成。两种 action 都不绑定具体服务，也不意味着必须重新生成已有可复用素材。

### layer_order 与 questions

- `layer_order`：条目为 `{"type":"background"}` 或 `{"type":"slot","id":"…"}`、`{"type":"text","id":"…"}`、`{"type":"overlay","id":"…"}`。固定背景以 background 条目开头；槽背景以对应 slot 条目开头，不再添加 background 条目。引用类型必须匹配所属数组。
- `questions`：非空字符串组成的数组，无疑点用 `[]`。每条指出对象或区域、未确定的具体事项及其对识别或制作的影响，不输出泛泛的“请确认”。

以下仅示范字段，不限定实际图片的数量、布局或元素种类：

```json
{
  "background": {"mode": "fixed", "kind": "solid", "background_brief": "暖白色底"},
  "slots": [
    {"id": "portrait", "label": "主体照片", "source_bbox_1000": [180, 230, 820, 880], "mode": "photo"}
  ],
  "texts": [
    {"id": "title", "label": "标题", "source_bbox_1000": [180, 90, 650, 155], "default_text": "周末记忆", "style_brief": "深蓝色手写风格，左对齐"}
  ],
  "overlays": [
    {"id": "accent", "label": "标题下的横线", "source_bbox_1000": [180, 182, 650, 190], "action": "basic_shape", "shape": {"kind": "line", "appearance_brief": "深蓝色水平实线，从左至右，笔画均匀"}}
  ],
  "layer_order": [
    {"type": "background"},
    {"type": "slot", "id": "portrait"},
    {"type": "text", "id": "title"},
    {"type": "overlay", "id": "accent"}
  ],
  "questions": []
}
```

## 5. 不确定性与表达边界

已有依据的对象保留最合理的分类与范围，将不确定点写清。连是否为独立设计对象都无法判断时，在 `questions` 描述位置和可能角色，不为了凑齐对象而编造。`mode=unknown`、未知背景、`default_text=null` 或 `text_content=null` 都需要对应问题；后续提供客户素材本身不算识别疑点。

主要照片漏项、内口与外框混淆、同源人物被当成独立固定装饰、必要遮挡无法表达，都会影响制作，不能被称为轻微边缘误差。相反，少量颜色或线宽近似不需要伪装成精确测量。

此格式记录包围范围、文字、基本角色、图层顺序及有限的同源关系。精确轮廓遮罩、旋转/透视变换、源图裁剪与对齐、字形复原、透明度取样尚未完成。遇到决定布局的这类关系，在说明中保留观察，并在 `questions` 明确待解决的制作条件；不能因为结构合法就宣布可直接出图。
