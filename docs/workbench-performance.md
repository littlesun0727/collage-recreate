# 窄带宽下的工作台

这些优化内置于工作台，无需逐个任务处理。新增图片首次被查看时自动生成预览，编辑和下载继续使用原始文件。

- 侧栏和客户照片选择器请求最长边 160px 的 WebP；素材和历史版本卡片使用 480px；主画布使用 1280px。点击原图查看完整分辨率。
- 切换任务直接请求详情，不等待全部列表；列表每 15 秒更新，当前任务每 5 秒更新，后台标签页暂停轮询。新增任务最多等待一个列表更新周期即可出现。
- 已知任务详情复用目录索引，仍检查目录存在和路径边界；列表读取状态时不再遍历成图资源做路径迁移。缓存命中的预览不再等待其他图片编码。
- 服务端合并相同读取请求，任务/批次列表最多复用 5 秒、详情最多复用 2 秒，最多保留 64 项；这只影响状态展示延迟，提交修改、上传、token 校验不会经过该缓存。
- 图片 URL 包含路径、裁剪区域、文件大小和纳秒修改时间的摘要。文件更新会产生新 URL，浏览器可长期缓存旧版本而不会阻止新图出现。替换图片的外部工具应正常更新修改时间。
- 预览存放在 `--media-root` 下的 `preview-cache`，默认使用运行目录的 `service/preview-cache`。缓存可删除，自动重建；服务重启后仍可复用。
- 预览生成串行进行，避免并发解码大图占满内存。写入采用临时文件和原子替换；缓存不可写时直接返回生成的预览。
- 生成新预览时最多每分钟清理一次缓存，按最早写入顺序淘汰至 512 MiB；两次清理之间可能暂时超出此值。仅清理缓存文件，不删除任务原图。
- 卡片图片懒加载、异步解码；HTML、JS、CSS、JSON 根据浏览器能力使用 gzip。动态 API 保持 `no-store`，避免任务状态或会话 token 过期。
- 技术说明的两张配图仅在打开说明对话框时下载，不再嵌入首页。

更新代码后，需在任务空闲时重启工作台后端，再刷新浏览器。仅重新运行 `launch.py` 会复用已有进程，不会加载新的 Python 代码。公网反向代理须保留查询参数、`Accept-Encoding`、`Content-Encoding` 和 `Cache-Control`。

验证：

```powershell
& .\.venv\Scripts\python.exe -m pytest tests/test_workbench_previews.py tests/test_workbench_stages.py -q
node --check workbench/web/app.js
```

浏览器网络面板中，列表图片应为 `?size=480`、`image/webp`；主预览为 `?size=1280`；刷新后图片应命中浏览器缓存。下载链接仍返回原文件。缓存只优化传输与重复编码，不改变生成任务耗时，也不能保证任何规模下都不会出现资源瓶颈。
