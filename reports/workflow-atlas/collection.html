阶段输入、判断与产物

01 / COLLECT

关键词搜索与详情

collect-only.ps1 调用 pipeline.py collect；MediaCrawler 独立 worker 使用登录会话，导入搜索及笔记详情。按关键词文本保存轮次、页码、offset；只有成功批次推进游标。连续 3 页新笔记占比 ≤10% 可提前换词，冷却中的词不参与调度。权重分配整轮机会，不是图片配额或审核通过率。

产物 / 状态
collections/；catalog.sqlite：notes、images、pipeline_state

源码依据：template_download/collect-only.ps1 · template_download/search_scheduler.py · template_download/mediacrawler_worker.py · template_download/stage_cli.py · template_download/config.1000.json

02 / DOWNLOAD

原始文件落盘

collect_media 只下载原始字节，不运行 Pillow、质量筛选或 VLM。封面保存 .bin，Live 保存 MP4；写完文件和 SHA-256 后才提交 raw_assets=ready。下载最多按配置尝试 3 次；访问限制保存断点并停止。collect-only 不会自动启动 screen/review/export。

产物 / 状态
raw/cover/、raw/live/；raw_assets 状态与 SHA-256

源码依据：template_download/stage_media.py · template_download/store.py

03 / SCREEN

离线初筛与去重

screen_local 不发网络请求。校验原始 SHA-256、图片解码和 Live MP4，Live 文件不齐继续等待。质量合格后发布 images 路径，静态图用 SHA 与 dHash 去重；Live 按封面及视频哈希配对去重。失败或重复记录保留，原始文件不删除。

产物 / 状态
images/；ready 候选队列 / rejected / duplicate / near_duplicate

源码依据：template_download/stage_media.py · template_download/quality.py · template_download/live_media.py

04 / REVIEW · TRIAGE

VLM 只做分类

一张完整拼贴（内部可以有多个照片槽）才是 single；一图多套独立设计是 collection。分类阶段只输出 id、label、needs_crop，不输出框。single 且无需裁剪直接进入最终处理；single 且 needs_crop 才送定位。collection/other 拒绝，unsure 待人工处理。尾批需 --flush。

产物 / 状态
review_cache；vlm-reports/*-triage-*.json

源码依据：template_download/pipeline.py · template_download/vlm_batch.py · template_download/vlm_stages.py · template_download/stage_cli.py

05 / REVIEW · LOCATE

按需定位完整画布

定位整套作品的外矩形，去掉外部 UI 和无关边缘；保留作品自己的留白、标题、装饰和所有照片槽。画布被截断或 UI 遮挡时返回 review。归一化框映射回原图，edge_snap 在本地调整边界；未确认边界保留 VLM 坐标。定位缺失保持 pending，不能当作 keep。

产物 / 状态
vlm-reports/*-locate-*.json；像素裁剪框与 edge_snap

源码依据：template_download/pipeline.py · template_download/vlm_stages.py · template_download/edge_snap.py

06 / PUBLISH

裁剪复核与导出

裁剪面积不足原图 25% 转人工；裁后仅分辨率不足记录告警，不自动否决；其他质量失败转人工。Live 裁剪需人工确认视频几何。静态图再次按像素哈希与感知哈希去重，近重复不会直接 accept。review 或 export 更新图库和清单，collect/screen 不覆盖最终审核导出。

产物 / 状态
processed/crop-v2/；accepted.jsonl；gallery.html；裁剪报告

源码依据：template_download/crop_review.py · template_download/dataset_preview.py · template_download/crop_report.py · template_download/stage_cli.py · template_download/store.py

分支与恢复机制

分类分支

single 无裁剪 → 最终处理；single 需裁剪 → 定位；collection / other → reject；unsure → 人工。

有界恢复

worker 默认超时 360 秒，普通故障最多重启 2 次。明确验证要求隔离账号并提醒；账号冷却回切预算持久化，不能靠重启刷新。人工验证后才使用 --resume-access。

VLM 恢复

每次调用最长等待 300 秒；TimeoutError 保存成功缓存并重建 App Server，等待 15/30 秒，最多补跑两次。格式校验错误不自动重试；已完成判定先落库，缺结果项待补跑。

存储与边界

各阶段使用同一 --data-dir；当前启动脚本默认 D:/datas/collage_templates。watch 仅轮询本地队列，不是系统自启动。图中展示的是代码能力，未新执行采集或付费模型。

def thumbnail(path, bbox=None):

        im=ImageOps.exif_transpose(source).convert('RGB')
    if bbox:
        ImageDraw.Draw(im).rectangle(pixel_box(bbox,*im.size),outline='red',width=max(3,im.width//200))

    out=io.BytesIO()

"""Apply VLM crop decisions at original resolution; preserve every source file."""
import hashlib
import io
import json
import math
import os

from PIL import Image, ImageOps

from quality import inspect_image, bands

VERSION = 'crop-v2'


def pixel_box(bbox, width, height):
    if len(bbox)!=4 or any(type(v) is not int or not 0<=v<=1000 for v in bbox):
        raise ValueError('invalid_bbox')
    left,top,right,bottom = bbox
    if left>=right or top>=bottom:
        raise ValueError('invalid_bbox')
    return (math.floor(left*width/1000), math.floor(top*height/1000),
            math.ceil(right*width/1000), math.ceil(bottom*height/1000))


def apply_decision(store, item, cfg):
    ident = int(item['id'])
    row = store.db.execute('SELECT * FROM images WHERE id=?',(ident,)).fetchone()
    action, bbox, reason = item['action'],item['bbox'],item['reason']
    status, decision = 'review','unsure'
    info, path, pixel_sha, dup_id = {}, None, None, None
    store.db.execute('DELETE FROM processed_bands WHERE image_id=?',(ident,))
    if action == 'reject':
        status,decision = 'rejected','reject'
    elif action in ('keep','crop'):
        source_path = store.root / row['path']
        with Image.open(source_path) as source:
            im = ImageOps.exif_transpose(source).convert('RGB')
        if action == 'crop':
            box = pixel_box(bbox,*im.size)
            if 'crop_pixels' in item:
                box=tuple(item['crop_pixels'])
                if len(box)!=4 or any(type(v) is not int for v in box) or not (0<=box[0]<box[2]<=im.width and 0<=box[1]<box[3]<=im.height):
                    raise ValueError('invalid_local_crop_pixels')
            if (box[2]-box[0])*(box[3]-box[1]) < im.width*im.height*.25:
                reason = 'crop_too_small_for_auto_accept'
            else:
                im = im.crop(box)
                status = 'ready'
        else:
            status = 'ready'
        if status == 'ready':
            encoded = io.BytesIO()
            im.save(encoded,format='PNG')
            normalized = encoded.getvalue()
            pixel_sha = hashlib.sha256(str(im.size).encode()+im.tobytes()).hexdigest()
            data = normalized if action=='crop' else source_path.read_bytes()
            info = inspect_image(data,cfg)
            path = row['path']
            if action == 'crop':
                path = f'processed/{VERSION}/{info["sha256"][:2]}/{info["sha256"]}.png'
                dest = store.root/path
                dest.parent.mkdir(parents=True,exist_ok=True)
                temp = dest.with_suffix('.part')
                temp.write_bytes(data)
                os.replace(temp,dest)
            resolution_warning = action=='crop' and info['reason']=='resolution'
            if resolution_warning:
                reason='post_crop_resolution'
            review_reason=item.get('needs_review_reason')
            if review_reason in ('local_boundary_unresolved','crop_predictions_disagree'):
                review_reason=None  # Retired program-only gates, including saved legacy decisions.
            if info['reason'] and not resolution_warning:
                status,reason = 'review','post_crop_'+info['reason']
            elif review_reason:
                status,reason = 'review',review_reason
            elif row['media_kind']=='live' and action=='crop':
                status,reason = 'review','live_video_geometry_unverified'
            else:
                same = store.db.execute('''SELECT p.image_id FROM processed_assets p JOIN images i ON i.id=p.image_id
                    WHERE p.pixel_sha256=? AND p.status='ready' AND p.image_id!=?
                    AND i.media_kind='image' ORDER BY p.image_id LIMIT 1''',(pixel_sha,ident)).fetchone()
                if row['media_kind']=='image' and same:
                    status,dup_id = 'duplicate',same[0]
                elif row['media_kind']=='image':
                    matches=set()
                    for b,v in bands(info['dhash']):
                        matches.update(r[0] for r in store.db.execute('SELECT image_id FROM processed_bands WHERE band=? AND value=?',(b,v)))
                    for candidate in sorted(matches):
                        other=store.db.execute('SELECT dhash FROM processed_assets WHERE image_id=?',(candidate,)).fetchone()
                        if (int(info['dhash'],16)^int(other[0],16)).bit_count()<=cfg['near_duplicate_distance']:
                            status,dup_id = 'near_duplicate',candidate
                            break
                if status=='ready':
                    decision='accept'
                    if row['media_kind']=='image':
                        store.db.executemany('INSERT OR IGNORE INTO processed_bands VALUES(?,?,?)',[(b,v,ident) for b,v in bands(info['dhash'])])
                elif status=='duplicate':
                    decision='reject'
    store.db.execute('''INSERT OR REPLACE INTO processed_assets
        (image_id,action,bbox,reason,path,sha256,pixel_sha256,dhash,width,height,status,duplicate_of,version)
        VALUES(?,?,?,?,?,?,?,?,?,?,?,?,?)''',
        (ident,action,json.dumps(bbox) if bbox else None,reason,path,info.get('sha256'),pixel_sha,
         info.get('dhash'),info.get('width'),info.get('height'),status,dup_id,VERSION))
    store.db.execute('UPDATE images SET review=? WHERE id=?',(decision,ident))

"""Conservative local snapping of VLM boxes to artwork/white screenshot boundaries.

Only examines +/-3% around each predicted edge. Invisible/ambiguous boundaries
remain unchanged and require review. This is a heuristic, not semantic segmentation.
"""
import numpy as np
from itertools import product

from crop_review import pixel_box

COMMON_RATIOS = {'1:1':1., '1:2':.5, '2:3':2/3, '3:2':1.5,
                 '3:4':.75, '4:3':4/3, '9:16':9/16, '16:9':16/9}


def refine_ratio(result, image_size, max_ratio_error=.03, max_edge_fraction=.02):
    """After boundary detection, anchor three edges and adjust the weakest fourth."""
    box=result['pixels']
    left,top,right,bottom=box
    width,height=right-left,bottom-top
    name,ratio=min(COMMON_RATIOS.items(),key=lambda kv:abs((width/height)/kv[1]-1))
    error=abs((width/height)/ratio-1)
    info={'applied':False,'ratio':name,'relative_error':error,'before_pixels':box.copy()}
    result=dict(result,ratio_adjustment=info)
    if error>max_ratio_error:
        info['reason']='ratio_too_far'
        return result
    desired=[right-round(height*ratio),bottom-round(width/ratio),
             left+round(height*ratio),top+round(width/ratio)]
    candidates=[]
    for index,edge in enumerate(('left','top','right','bottom')):
        evidence=result['edges'][edge]
        if evidence['status']=='image_edge':
            continue
        extent=image_size[0 if index in (0,2) else 1]
        span=width if index in (0,2) else height
        pos=desired[index]
        delta=pos-box[index]
        if not 0<=pos<=extent or abs(delta)>max_edge_fraction*span:
            continue
        trial=box.copy();trial[index]=pos
        if trial[0]>=trial[2] or trial[1]>=trial[3]:
            continue
        # Missing/ambiguous edges move first; detected strong edges serve as anchors.
        strength=evidence.get('score',0) if evidence['status']=='snapped' else -1
        candidates.append((strength,abs(delta)/span,index,trial))
    if not candidates:
        info['reason']='no_small_adjustment'
        return result
    _,_,index,trial=min(candidates)
    expands=(trial[index]<box[index]) if index in (0,1) else (trial[index]>box[index])
    if expands:
        info.update(reason='expansion_skipped',edge=('left','top','right','bottom')[index],
                    proposed_delta=trial[index]-box[index])
        return result
    info.update(applied=trial!=box,edge=('left','top','right','bottom')[index],
                delta=trial[index]-box[index],reason='anchored_ratio_adjustment')
    result['pixels']=trial
    # A ratio assumption does not resolve uncertain visual boundaries.
    return result


def postprocess_box(image, bbox, radius_fraction=.03):

def ratio_tiebreak(options, initial, radii):
    """Rank only comparable, observed edge candidates; never synthesize ratio-derived edges."""
    pools=[]
    for index, candidates in enumerate(options):
        if not candidates:
            return None
        best=max(candidates,key=lambda x:x['score'])
        nearest=abs(best['position']-initial[index])
        pool=[c for c in candidates if c['score']>=best['score']*.97 and
              abs(c['position']-initial[index])<=nearest+max(3,radii[index]*.15)]
        pools.append(pool[:3])
    ranked=[]
    for edges in product(*pools):
        box=[edge['position'] for edge in edges]
        width,height=box[2]-box[0],box[3]-box[1]
        if width<=0 or height<=0:
            continue
        ratio=width/height
        name,value=min(COMMON_RATIOS.items(),key=lambda kv:abs(ratio/kv[1]-1))
        ranked.append({'pixels':box,'ratio':name,'error':abs(ratio/value-1),'edges':edges})
    ranked.sort(key=lambda x:x['error'])
    if len(ranked)<2 or ranked[0]['error']>.02:
        return None
    # A weak ratio preference must not turn ambiguity into automatic acceptance.
    if ranked[1]['error']-ranked[0]['error']<.005:
        return None
    return dict(ranked[0],runner_up_error=ranked[1]['error'])


def snap_box(image, bbox, radius_fraction=.03, use_ratio_prior=True):
    im=np.asarray(image.convert('RGB'),dtype=np.float32)
    h,w=im.shape[:2]
    initial=list(pixel_box(bbox,w,h))
    result=initial.copy()
    evidence={}
    options=[]
    radii=[]
    # Use the central 80% of the opposite span to avoid rounded corners and outside UI.
    for index,name in enumerate(('left','top','right','bottom')):
        vertical=index in (0,2)
        extent=w if vertical else h
        prior=initial[index]
        radius=max(4,round(extent*radius_fraction))
        radii.append(radius)
        if prior in (0,extent):
            evidence[name]={'status':'image_edge','position':prior}
            options.append([{'position':prior,'score':1.0}])
            continue
        lo,hi=(initial[1],initial[3]) if vertical else (initial[0],initial[2])
        trim=max(1,int((hi-lo)*.1))
        lo,hi=lo+trim,hi-trim
        # Moving dimension first, RGB pixels along each line second.
        a=np.transpose(im[lo:hi,:,:],(1,0,2)) if vertical else im[:,lo:hi,:]
        candidates=[]
        for pos in range(max(4,prior-radius),min(extent-4,prior+radius)+1):
            before=a[pos-3:pos].mean(axis=0)
            after=a[pos:pos+3].mean(axis=0)
            outside,inside=(before,after) if index in (0,1) else (after,before)
            contrast=np.max(np.abs(before-after),axis=1)
            support=float(np.mean(contrast>=18))
            outside_white=float(np.mean(np.min(outside,axis=1)>=235))
            inside_content=float(np.mean(np.min(inside,axis=1)<225))
            if support<.65 or outside_white<.85 or inside_content<.6:
                continue
            jump=float(np.median(contrast))
            adjacent_jump=float(np.median(np.max(np.abs(a[pos]-a[pos-1]),axis=1)))
            # Broad transitions should beat isolated internal photo edges; proximity is secondary.
            score=support*min(jump/100,1.5)*outside_white+.5*adjacent_jump/255-.08*abs(pos-prior)/radius
            candidates.append({'position':pos,'support':round(support,4),
                'outside_white':round(outside_white,4),'inside_content':round(inside_content,4),
                'median_jump':round(jump,2),'adjacent_jump':round(adjacent_jump,2),'score':round(score,5)})
        candidates.sort(key=lambda x:x['score'],reverse=True)
        if not candidates:
            evidence[name]={'status':'unresolved','position':prior,'radius':radius}
            options.append([])
            continue
        best=candidates[0]
        rival=next((x for x in candidates if abs(x['position']-best['position'])>6),None)
        if rival and rival['score']>=best['score']*.85:
            evidence[name]={'status':'ambiguous','position':prior,'best':best,'rival':rival}
            # Nonmaximum suppression: one candidate per distinct boundary, not adjacent pixels.
            peaks=[]
            for candidate in candidates:
                if all(abs(candidate['position']-x['position'])>6 for x in peaks):
                    peaks.append(candidate)
                if len(peaks)==3:
                    break
            options.append(peaks)
            continue
        options.append([best])
        result[index]=best['position']
        evidence[name]=dict(best,status='snapped',delta=best['position']-prior,radius=radius)
    ratio_evidence={'enabled':use_ratio_prior,'applied':False}
    if use_ratio_prior and any(e['status']=='ambiguous' for e in evidence.values()):
        choice=ratio_tiebreak(options,initial,radii)
        if choice:
            result=choice['pixels']
            ratio_evidence.update(applied=True,ratio=choice['ratio'],relative_error=choice['error'],
                                  runner_up_error=choice['runner_up_error'])
            for index,name in enumerate(('left','top','right','bottom')):
                if evidence[name]['status']=='ambiguous':
                    evidence[name]=dict(choice['edges'][index],status='snapped',
                        delta=result[index]-initial[index],radius=radii[index],selection='ratio_tiebreak')
    if result[0]>=result[2] or result[1]>=result[3]:
        return {'coarse_pixels':initial,'pixels':initial,'status':'review','edges':evidence,'reason':'invalid_geometry'}
    resolved=all(x['status'] in ('snapped','image_edge') for x in evidence.values())
    return {'coarse_pixels':initial,'pixels':result,'status':'resolved' if resolved else 'review',
            'edges':evidence,'ratio_prior':ratio_evidence}

def task():
    return dict(page=1, offset=0, round=0, low_streak=0, pages=0,
                seen=0, new=0, rounds=0, due=0, status='pending', low_rounds=0)


def prepare(cfg, saved=None, legacy=None):

    if state['version'] != 1:
        raise ValueError('Unsupported search scheduler version')

def select(state, cfg, now=None):
    now = time.time() if now is None else now
    options = settings(cfg)
    # A lower cap applies to saved cursors too; never request an old deeper page.
    for keyword in cfg['keywords']:
        entry = state['tasks'][keyword]
        if entry['page'] > options['max_pages']:
            finish_round(entry, options, 'page_limit', now)
            if state.get('active') == keyword:
                state['active'] = None
    active = state.get('active')
    if active not in cfg['keywords']:
        active = None
    if active is None:
        eligible = [k for k in cfg['keywords'] if state['tasks'][k]['due'] <= now]
        if not eligible:
            return None
        # Smooth weighted rotation, charged once per whole keyword round.
        # Cooling words earn no credit; page/batch retries never charge again.
        priority = next((k for k in state.get('priority_queue', []) if k in eligible), None)
        if priority is not None:
            active = priority
            state['priority_queue'].remove(priority)

            for keyword in eligible:
                entry = state['tasks'][keyword]
                entry['schedule_credit'] = entry.get('schedule_credit', 0) + weights[keyword]

            if edge is not None:
                im.thumbnail((edge, edge))
            out = io.BytesIO()
            if edge is None:
                im.save(out, format='PNG')
            else:
                im.save(out, format='JPEG', quality=85)
        inputs.extend([{'type': 'text', 'text': 'image id: ' + wire_id},

                        base64.b64encode(out.getvalue()).decode('ascii')}, **({'detail':'original'} if edge is None else {}))])
    return inputs, wire_rows

    def _read_stderr(self):
        # Keep only fixed diagnostic categories, never raw logs, URLs or credentials.
        for line in self.child.stderr:
            lower=line.lower()
            labels=[word for word in ('websocket','timed out','timeout','retry','reconnect',
                'fallback','connection','stream disconnected','error','failed') if word in lower]
            labels.extend('http_'+code for code in re.findall(r'\b(?:status(?: code)?[=: ]+)(401|403|429|500|502|503|504)\b',lower))
            with self.lock:
                self.transport_diagnostics.update(labels)

    def send(self, message):
        with self.lock:
            self.child.stdin.write(json.dumps(message) + '\n')
            self.child.stdin.flush()

    def _read(self):
        try:
            for line in self.child.stdout:
                msg = json.loads(line)
                with self.lock:
                    if 'id' in msg and 'method' not in msg:
                        target = self.pending.get(msg['id'])
                        if target is not None:
                            target.put(msg)
                    elif 'id' in msg:
                        self.send({'id': msg['id'], 'error': {'code': -32601, 'message': 'Tools disabled'}})
                    else:
                        params = msg.get('params', {})
                        tid = params.get('threadId') or params.get('thread_id')
                        if tid:
                            self.events.setdefault(tid, queue.Queue()).put(msg)
                        else:
                            self.unrouted_notifications[msg.get('method', 'unknown')] += 1
        finally:
            with self.lock:
                for target in self.pending.values():
                    target.put({'error': {'message': 'Codex app server closed'}})
                for target in self.events.values():
                    target.put({'method': 'transport_closed'})

    def rpc(self, method, params, timeout=45):
        with self.lock:
            self.counter += 1
            rid = self.counter
            response = self.pending[rid] = queue.Queue()
        try:
            self.send({'id': rid, 'method': method, 'params': params})
            try:
                msg = response.get(timeout=timeout)
            except queue.Empty:
                raise TimeoutError('App Server RPC timeout: ' + method) from None
            if 'error' in msg:
                raise RuntimeError(str(msg['error'].get('message', 'RPC error'))[:500])
            return msg.get('result')
        finally:
            with self.lock:
                self.pending.pop(rid, None)

                raise RuntimeError('Requested model was rerouted at thread/start')
            started = self.rpc('turn/start', {'threadId': tid, 'model': model, 'effort': effort,
                'serviceTier': 'default', 'serviceTierForTurn': 'default',
                'input': inputs, 'approvalPolicy': 'never',
                'sandboxPolicy': {'type': 'readOnly', 'networkAccess': False},
                'outputSchema': schema})
            turn_id = started['turn']['id']
            deadline = time.monotonic() + timeout
            while True:
                try:
                    msg = events.get(timeout=max(.01, deadline - time.monotonic()))
                except queue.Empty:
                    diagnostic = {'model': model, 'stage': stage, 'images': len(rows),
                                  'timeout_seconds': timeout, 'events': dict(event_counts),
                                  'elapsed_seconds': round(time.perf_counter()-start, 3),

                    if not p.get('willRetry'):
                        raise RuntimeError(str(p.get('error', {}))[:500])

                pass

                self.events.pop(tid, None)

def schema(properties):
