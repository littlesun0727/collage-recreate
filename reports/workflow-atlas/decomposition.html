02 / ANALYZE

视觉分析与模型路由

默认 codex-auto 先用 gpt-6-luna，排除全画布背景后前景超过 18 个，升级 gpt-6.1-sol；18 个仍用 Luna。Sol 用同一原图与提示词独立分析，升级失败停止，不静默回退。固定 Qwen3.8-Flash 默认为 thinking off；不设置分析对象数上限。

源码依据：reveal-layer-lab/data_workflow.py · reveal-layer-lab/prompts/analyze-source.md

03 / CONTRACT

校验与像素坐标统一

默认坐标策略按模型家族，不按服务商。原始模型对象写入 analysis/structure.json，转换后写 source-analysis.json。检查对象 ID、框、关系、层序和背景；背景必须唯一、全画布且在底层，不自动扩大错误背景框。显式 Codex normalized_1000 是另一条 1000×1000 副本路径；更改坐标/模型/提示词须新建 run。

EXTRACTION_PAUSED.json 存在即阻止主工作流的 360 提取；需明确恢复后才可继续。恢复后的 chain_workflow 按原 layer_order 从上往下分批，不提交背景框，不重新分析；框按当前画布缩放。每批提交、轮询、下载保留任务 ID，提交结果未知时不自动重复扣费。

05 / LAYERS

收集素材与最终背景

缺图层、缺 base/aug、空 Alpha 或画布尺寸变化立即停止。中间背景不重复叠加；只把最后一批 layer_0 作为最终背景。aug 与 base 由同一条 base 驱动链产生，不额外跑第二条提取链。原始 background_type 只作来源标注，不保证接口产生相同语义或透明背景。

06 / DATASET

本地合成与标注

每个裁片按 z_index 升序，以原尺寸放在 crop_bbox 左上角做 source-over 合成；不要用 source_object.bbox 重定位或再次缩放。bbox 表示完整素材范围，不是遮挡后可见范围。新 reference 不要求与输入逐像素相同；complete 代表产物完整，visual_review 仍为 pending。

产物 / 状态
reference[-base/-aug].png；analysis*.json；dataset.jsonl；manifest.json；index.html

源码依据：reveal-layer-lab/chain_workflow.py · reveal-layer-lab/data_workflow.py · reveal-layer-lab/usage_report.py

分支与恢复机制

模型分支

Luna 前景数 ≤18：采用 Luna；>18：Sol 独立分析并采用 Sol；升级失败：停止。--analysis-json 可跳过这一步。

当前可用终点

--analyze-only 输出 source-analysis.json 和 analysis-boxes.png 后结束。暂停标记保持原样；本次文档整理没有恢复或调用 360。

分批回路

批次 N 的 base 剩余背景 → 批次 N+1；没有下一批时汇总。background_type、linked_to 不作为 Reveal 远端指令；只提交图像、前景 image_boxes 等参数。

重建与质检

base 素材只配 reference-base，aug 素材只配 reference-aug。最初文字/字体/关系保留 source_object，不作为已核实语义。检查 index.html 和 comparison/index.html，再做人工视觉验收。

运行锁阻止同目录并发；相同输入、配置与计划可复用缓存，提交未知需核查响应。usage.csv/usage-summary.json 记录请求用量，缺失用量为未知，不重复加推理 token。

def plan_batches(analysis, batch_size=20):
    if not 1 <= batch_size <= 20:
        raise ValueError('Batch size must be between 1 and 20')
    # layer_order is bottom-to-top; remove upper layers before underlying ones.
    top_down = [i for i in reversed(analysis['layer_order']) if i != 'layer_0']
    return [top_down[n:n+batch_size] for n in range(0, len(top_down), batch_size)]


def scaled_analysis(source, ids, size):
    sw, sh = source['reference_size']
    w, h = size
    objects = []
    for original in source['objects']:
        if original['id'] not in ids:
            continue
        item = copy.deepcopy(original)
        item['bbox'] = [round(v * (w/sw if n % 2 == 0 else h/sh))
                        for n, v in enumerate(item['bbox'])]
        l, t, r, b = item['bbox']
        if not 0 <= l < r <= w or not 0 <= t < b <= h:
            raise ValueError('Invalid batch box: ' + item['id'])
        objects.append(item)
    return {'reference_size': list(size), 'objects': objects,
            'layer_order': [i for i in source['layer_order'] if i in ids]}

def remove_trailing_commas(text):
    """Remove only commas immediately before closing JSON containers, outside strings."""
    result=[];quoted=False;escaped=False
    for i,char in enumerate(text):
        if quoted:
            result.append(char)
            if escaped:escaped=False
            elif char=='\\':escaped=True
            elif char=='"':quoted=False
        else:
            if char=='"':quoted=True
            if char==',':
                j=i+1
                while j<len(text) and text[j].isspace():j+=1
                if j<len(text) and text[j] in '}]':continue
            result.append(char)
    return ''.join(result)

def routed_analysis(image, prompt, stage, size, mode, keys, timeout):

    compiled=compile_analysis(first,size,mode)

    upgrade=count>policy['foreground_threshold']
    selected='sol' if upgrade else 'luna'
    decision={**policy,'coordinate_mode':mode,'luna_foreground_count':count,'upgrade_required':upgrade,
              'selected_model':policy['upgrade_model'] if upgrade else policy['first_model'],
              'selected_stage':selected,'status':'awaiting_upgrade' if upgrade else 'complete'}
    save(stage/'routing.json',decision)

            decision['status']='upgrade_failed';save(stage/'routing.json',decision)

    # Publish only the selected, validated result. An upgrade failure never submits Luna to 360.
    for filename in ('response.txt','receipt.json','structure.json'):
        shutil.copyfile(stage/selected/filename,stage/filename)
    decision['status']='complete';save(stage/'routing.json',decision)
    return value

## 设计判断规则

### background：先确定唯一画布背景

每张图必须恰好建立一个 kind=background 的对象，建议 ID 为 background，放在 layer_order 第一项。只有该对象填写 background_type，其他对象不得再使用 kind=background 或填写 background_type。它是整张画布的底层，不是人物身后的摄影环境，也不是对多个照片的分组。

先判断画布底层是完整摄影内容、固定设计还是纯色，选择以下一种来源；background_type 只记录来源语义，不决定调用不同的制作或绘制流程：

- background_type=photo：一张原图照片铺底。人物、天空、草地、建筑及照片中的其他摄影内容作为同一个完整单元保留，kind 仍为 background。不要把同一摄影图像拆成固定环境 background 和局部人物 photo；不填写 color。
- background_type=reference_clean：底层是需要保留的固定纹理、纸张、印刷图案或设计结构，后续清除独立前景并保留底图。实拍固定模板也可属于此类，判断依据是设计用途而不是是否写实。不填写 color，不用移除照片人物、保留其摄影环境的方式制造固定底图。
- background_type=simple_design：底层可由明确的纯色表达，填写 color。复杂材质不能用猜测的颜色替代。如果多张独立照片拼满整个画布、没有可见独立底图，用 color="#00000000" 表示透明画布占位，在 description 中说明没有可见底图；不得虚构隐藏纹理或额外的“整体拼贴照片”。各照片保留独立范围，不将其中一张强行铺满。

背景 bbox 始终覆盖整个画布，按本次坐标约定填写。人物只占局部、照片被装饰遮挡，都不改变铺底范围。程序校验全画布范围，并将背景 ID 统一为 layer_0；不要依赖程序修补局部背景框。

例如：人物站在草地上的全画幅照片，上面叠加播放器小照片和贴纸。应建立一个 background_type=photo 的 background，包含人物和草地环境；小照片及贴纸另列。不要建立固定草地背景，再建立只框人物附近的主照片。

### 完整单元如何划分

确定画布背景后，再确定上层照片内容及其依附效果、需要保留的固定设计单元，最后根据独立性和遮挡关系决定是否拆分。物件名称、颜色、题材、是否写实或容易分割，都不能单独决定分类。

同一局部设计的内部图案、笔画、印字、描边、阴影和附属点缀整体保留，成员之间有透明空隙也不必拆开。拆分需要有独立照片显示、独立设计单元或外部遮挡关系的依据，不能仅因内部成员可单独识别或编辑就拆分。距离较远的独立素材不因颜色、主题或底板相同而合并；相邻、相交也不等于属于同一单元。

每个可见成员只能归属一个完整单元。组合内存在独立照片时，照片单列，固定载体保留；不能为整体提取而吞掉照片。独立固定素材按完整单元提取，保留轮廓、内部设计、材质和边缘，不拆成基础图形重画，也不把复杂材质简化为填色。

每个上层独立显示的照片位置建立一个 photo。摄影内容指被拍摄场景本身，其中的物体、文字和环境随照片整体保留。位于照片显示区域内不等于属于摄影内容；后加的设计元素按下述依附关系判断归属。抠图范围包含完整主体组合，不限于人体。多张照片保持独立，不额外建立包含它们的整组照片。

实拍画面也按完整单元判断：独立照片内口与其固定载体分别识别，固定模板的实拍材质可以保留。照片描述写清主体、人数、景别、姿态朝向、位置和遮挡，供后续提取与标注核对；不把参考照片中的物品当作必须额外补充的固定装饰。

    pricing=read(pricing_path) if pricing_path.exists() else {}
    groups={}
    for row in requests:
        model=row['model'];g=groups.setdefault(model,{'requests':0,'usage_reported_requests':0,'unknown_or_pending_requests':0,
                'known_input_tokens':0,'known_output_tokens':0,'known_total_tokens':0,
                'known_reasoning_output_tokens':0,'known_image_input_tokens':0,
                'estimated_cost_for_priced_requests':0,'priced_requests':0,'currency':None})
        g['requests']+=1;g['usage_reported_requests']+=row['usage_status']=='reported'
        g['unknown_or_pending_requests']+=row['usage_status']!='reported'
        for source,target in [('input_tokens','known_input_tokens'),('output_tokens','known_output_tokens'),
                              ('total_tokens','known_total_tokens'),('reasoning_output_tokens','known_reasoning_output_tokens'),
                              ('image_input_tokens','known_image_input_tokens')]:
            if isinstance(row[source],(int,float)):g[target]+=row[source]
        rate=pricing.get(model,{})
        row['estimated_cost']=None;row['currency']=rate.get('currency')
        if all(isinstance(v,(int,float)) and v>=0 for v in
               (row['input_tokens'],row['output_tokens'],rate.get('input_per_million'),rate.get('output_per_million'))) and row['currency']:
            cached_rate=rate.get('cached_input_per_million')
            cached=row['cached_input_tokens']
            if cached_rate is None:
                input_cost=row['input_tokens']*rate['input_per_million']
            elif isinstance(cached_rate,(int,float)) and isinstance(cached,(int,float)) and 0<=cached<=row['input_tokens']:
                input_cost=(row['input_tokens']-cached)*rate['input_per_million']+cached*cached_rate
            else:continue
            row['estimated_cost']=(input_cost+row['output_tokens']*rate['output_per_million'])/1_000_000
            g['estimated_cost_for_priced_requests']+=row['estimated_cost'];g['priced_requests']+=1;g['currency']=row['currency']
    for g in groups.values():
        if not g['priced_requests']:g['estimated_cost_for_priced_requests']=None
    result={'requests':requests,'by_model':groups,
            'notes':['Totals cover reported usage only. Missing usage is unknown, not zero.',
                     'Reasoning tokens are a subset of output tokens; image/cached tokens are subsets of input. Do not add them again.',
                     'Estimates use your configured Yibu rates, not assumed official model pricing. Account billing is authoritative.',
                     'A failed JSON/validation result can still consume tokens. Cached re-runs count the original request once.']}
    (out/'usage-summary.json').write_text(json.dumps(result,ensure_ascii=False,indent=2),encoding='utf-8')
    fields=['case','stage','provider','model','thinking','case_status','request_id','started_at','elapsed_seconds',
            'input_tokens','output_tokens','total_tokens','cached_input_tokens','image_input_tokens','text_input_tokens',
            'reasoning_output_tokens','finish_reason','usage_status','estimated_cost','currency','receipt','billing_fields']
    with (out/'usage.csv').open('w',encoding='utf-8-sig',newline='') as stream:
        writer=csv.DictWriter(stream,fieldnames=fields,extrasaction='ignore');writer.writeheader()
        for row in requests:writer.writerow({**row,'billing_fields':json.dumps(row['billing_fields'],ensure_ascii=False)})
    return result
