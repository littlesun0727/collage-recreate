Agent 写入 · 描述设计

画面里有什么，放在哪里？

reference_size
参考图原始宽高；所有 bbox 都用这套像素坐标。
objects / id / kind
对象清单与稳定 ID。类型分为 background、photo、frame、text、overlay；frame 表示需要独立提取的装饰相框。
photo_id
frame 必须关联承载的 photo。简单几何单色轮廓属于照片，不单独提取。
bbox
[左, 上, 右, 下]，与上图高亮框对应。若有 rotation，框绕中心旋转。frame 覆盖框体外沿，photo 表示照片内口。
mode / method
照片使用 cover、cutout、feather、stroke 初筛效果；frame 使用 extract 提取，普通装饰可用 extract 或 local。
layer_order
完整文件还包含从底到顶的顺序。当前对象片段不包含全图层级。

分析文件定义“设计关系”；具体使用哪张客户照片，交给 bindings。

先做 schema / 关联校验，再实际查看叠框。程序校验通过只说明数据合法，定位是否正确仍需看图。

分组提取与坐标还原

默认 grouped 模式按空间位置规划 1–3 组，每任务最多 3 次提取提交、每组最多 20 框（含照片辅助框）。分组保留独立对象 ID。

局部返回图层映射回原图坐标；保留原始缓存与来源哈希。简单几何本地绘制，复杂装饰缺失如实记录。

制作状态与视觉质量分开

动态阶段不逐帧调用大模型VLM 完成布局分析与素材筛选；视频解码、分割、合成与编码由脚本执行。

可追踪、可接续的执行

任务状态、事件、素材和版本快照落盘，浏览器关闭后仍能查看结果。上传预处理使用独立队列；制作与动态渲染受队列和任务锁管理。

request_id 用于幂等重试；render_id 和哈希约束基础版本。提取超时接续已有请求，避免重复提交结果未知的任务。

复核边界与性能瓶颈

当前 BiRefNet 为 CPU 逐帧推理，首次人物抠图较慢；缓存减少后续修改的重复推理。逐帧分割不保证时间连续性，尚需检查发丝、边缘闪烁与循环接缝。

支持图片与 MP4/MOV，首个有效帧作为封面；暂不支持 Live Photo 自动配对、GIF 导出和音轨混音。

    PAPER WALKTHROUGH · 360 AI RESEARCH

    RevealLayer 一张图，拆成可独立编辑的透明图层

    WHAT THE MODEL LEARNS

    把 FLUX.1-dev 改造成按框控制的多图层生成模型

    给定整张 RGB 图和 N 个对象框，联合预测背景与 N 个 RGBA 前景；可见部分保持一致，被遮挡部分由生成模型推断补全。

    原论文 Figure 3
    输入条件 RGB 图 I + N 个 bbox→RevealLayer-DiT FLUX.1-dev / MM-DiT + LoRA→输出 背景 + N 个 RGBA 前景
    ① 图上方 · 序列怎么组成

    把不同图层拼成一条 token 序列

    VAE 编码原图、背景和前景；前景 latent 按 bbox 裁剪，再与整图、背景及文本 token 拼接。用 3D-RoPE 区分图层与空间位置，支持可变数量、不同大小的图层。

    ② 图右侧 · RAA 注意力矩阵

    限定每层“能看谁”，减少串层

    绿色表示允许注意，白色表示屏蔽。前景 token 主要关注本层、原图中对应框区域及文本；背景保留全局上下文。把区域约束直接放进 attention mask。

    ③ 图中左侧 · OGA 适配器

    用可见局部信息帮助补全遮挡

    在 Double Attention Blocks 后，将每层 latent 与原图中对应的可见区域特征沿通道拼接，再做注意力融合。区域 mask 排除其他框的重叠干扰，帮助推断被挡住的结构。

    ④ 图下方 · 解码与监督

    还原到画布，解码 RGB + alpha

    目标层 latent reshape 并贴回对应位置，经 TransVAE 解码透明图层。它来自 ART，并在自然图像上微调；训练同时监督生成流场、透明边界和前背景残留。

    读图时要分清训练与推理：图上方的 Background / Fg1 / Fg2 / Fg3 是训练时的目标图层。推理时只提供原图、框及固定分层文本条件，待生成的图层从噪声开始；用户不需要先提供拆好的图层。
    论文方法与我们调用的 ecommerce_layer v1.1 的具体版本对应关系未确认。此处讲公开方法，项目接入见第 03 页。论文 §3 ↗
    DATA → SUPERVISION → OPTIMIZATION

    先制作成对的完整图层，再训练模型从合成图反推图层

    训练样本包含：原图 I、干净背景 BG、各对象完整 RGBA 和 bbox。训练集 RevealLayer-100K；评测集 RevealLayerBench 共 200 张。

    原论文 Figure 4

    ① 找对象、定位置与层级

    从 LAION-2B、GRIT-20M 和内部图像出发。Qwen3-VL 筛图、描述对象；Florence-2 给框，InstaOrder 判断提取顺序。

    ② 制作前景与干净背景

    SAM-H + ViTMatte 得到精细前景和 alpha；Qwen-Image-Edit 逐层去除、补全图像。通过背景一致性过滤与人工复核保留合格样本。

    ③ 补足干净背景与遮挡样本

    另外用 QwenVL + Zimage 生成背景，再用 Qwen-Image-Edit 插入对象、制造重叠。训练与评测按原始来源隔离，避免同源图泄漏。

    一次训练迭代怎么走条件图像保持可见，目标图层参与加噪与预测
    1. 1. 编码目标把 BG / RGBA 标签编码为 latent；前景按框裁剪，保留原图作为条件。
    2. 2. 采样噪声与 t把目标层 latent 与高斯噪声按时间步混合，形成模型要恢复的中间状态。
    3. 3. 联合预测流场带 RAA / OGA 的 FLUX 根据图像、框和固定文本条件，预测每个目标层的速度。
    4. 4. 解码并优化估计干净 latent，解码 RGBA；计算生成、alpha 与正交损失，反向更新训练参数。

    用什么模型、怎么微调

    生成底模FLUX.1-dev，MM-DiT 主干
    适配方式FLUX 用 LoRA 微调，rank = 64；加入 RAA / OGA
    透明编码器ART 的 TransVAE，在自然图像域微调
    训练配置50,000 iterations · global batch 8 · 图像长边 1024
    优化器Prodigy · learning rate 1.0（论文指定配置）

    三项损失分别解决什么

    L = LFM + λαLα + λoLorth λα = λo = 1
    Flow Matching · 内容生成
    约束各层预测流场与目标流场一致，学习从噪声恢复背景及前景。
    Alpha loss · 边界与透明度
    解码预测 RGBA，与真实 alpha 对比；focal 风格惩罚重点关注难分的边界像素。
    Orthogonality loss · 减少背景残影
    在对象框内，将预测前景与背景的 RGB 余弦关系对齐标签，抑制背景里残留的对象结构。
    以上为论文训练配置；本工作台通过 API 使用模型。数据制造模型只在离线标注阶段工作，在线推理的主体是训练好的 RevealLayer。论文 §4.1 ↗ · 数据细节 Appendix A ↗
    本项目实际调用海报分层 ecommerce_layer v1.1 · pipeline_type: crop · 28 采样步 · seed 42。框由 Agent 分析、本地程序组织；此路径不调用自动检测接口。
    INPUT

    带上下文的图像 + 目标框

    输入参考图或分组裁图，以及 image_boxes。框用上传图坐标；同时携带必要的照片辅助框，帮助区分相框与照片窗口。

    输入不含客户替换照片；客户照片在本地合成阶段加入。
    I2I / LAYER DECOMPOSITION

    按区域条件分离图层

    保持目标的外观与局部结构，分离其它对象和背景，得到透明前景。可见内容保真、遮挡处补全和边缘透明度需要共同处理。

    遮挡补全是模型推断，不能保证还原不可见的真实原图。
    OUTPUT

    PNG 图层 + 索引与坐标

    layers_base / layers_aug 返回图层地址；boxes_mapping_index 指回输入框，坐标元数据用于还原图层。

    本地优先读取可用的 aug 层，回退 base；00 背景层和辅助照片层不用于装饰回填。
    本地适配链路原图 bbox → 有限扩框 → 空间分组 / 裁图 → 异步提交与查询 → 图层索引匹配 → 缩放并贴回原图坐标 → 素材门禁 → scene 合成

    本项目限制每任务最多 3 次提交、每组最多 20 框（含辅助框）；这是本地调用预算。服务可能过滤框，因此不能假定每个输入框都有返回图层。
