# 手动画布编辑实施计划

日期：2026-10-09。范围：照片和贴纸拖动、独立文字编辑、撤销重做、预览和保存版本。沿用本仓库 skill / workbench 两个目录，不新建项目。

状态：首版已实现并完成真实浏览器拖动、文字修改、预览与保存测试。原始制作回归、真实样片新旧渲染器哈希对比通过；最终验证记录见 VALIDATION.md。

## 不影响原始制作

分析、提取、照片匹配、build 的输入格式和默认调用不变。编辑变换为可选字段，无字段时沿用原像素合成路径。原始素材和参考坐标不覆盖。编辑入口独立启用；不经过 Codex SDK，不提交提取/生成请求。手动版本显示未重新复核，不继承原图复核通过结论。

## 数据和渲染

- scene.json 对象新增可选 editor_transform，第一版记录参考坐标系的 x/y 位移。现有 bbox、extracted_offset、裁切和旋转保持原语义。
- 普通照片、提取透明贴纸、独立文字均以现有渲染器生成的实际 RGBA 图层参与编辑；原有遮罩、字体、阴影保持同一实现。
- 照片与其明确关联相框默认整组移动。嵌入文字和融合素材只作为所属图片的一部分，不假装可独立改字。
- 独立文字通过现有 text 渲染器预览，保留自动适配文字框的字号行为。
- 图层导出只在编辑缓存副本启用；不增加普通 build 的图层输出开销。

## 后端接口

- GET /api/tasks/:id/editor：读取当前版本的图层、对象能力、组合关系和编辑坐标。
- POST /api/tasks/:id/editor/preview：提交草稿，异步返回预览任务。
- POST /api/tasks/:id/editor/save：提交明确变更，异步渲染保存新版本。
- GET /api/tasks/:id/editor/jobs/:request_id：查询执行状态和预览/新版本。
- 请求使用 request_id、base_version_id、对象变更列表；检查幂等键、版本冲突及对象能力。复用任务写锁，避免与对话并发覆盖。
- 制作候选副本后再发布，发布失败可以恢复并重试。编辑不要求模型复核，旧版本及素材来源保留。

## 前端

新增独立编辑窗口和 editor.js，SVG 中按层级显示图层图片。点击选中，拖动改变位置；空格拖动画布，滚轮缩放；双击独立文字或使用文字输入框修改。透明区域不挡住下层选择，另提供对象列表。撤销/重做、草稿本机持久化、预览、保存、错误提示齐全。观察页轮询不覆盖草稿。成功保存后更新现有版本链，仍可继续对话。

## 验证与交付

1. 旧版与新版对同一输入的无编辑渲染逐像素/哈希对比；全量原有测试回归。
2. 位移后图层及照片遮罩一致、相框组合移动、独立文字渲染、旧任务无字段兼容。
3. 保存后重新渲染一致；旧快照不变；过期版本、非法对象、重复请求、失败恢复、预览不改正式结果。
4. 在指定样片“拼贴3”和原客户素材基础上建立独立验收任务，实际浏览器拖动照片、拖动贴纸、修改文字、撤销/重做、刷新恢复及保存后再编辑。逐项串行执行，原测试样本不覆盖。
5. 本地报告、截图和耗时保存在仓库外；代码及计划提交现有分支。

SVG 在本版用于编辑显示，不宣称将提取文字矢量化。本版不扩展任意旋转/缩放控件、重做提取、远程客户登录或素材内部修图。
